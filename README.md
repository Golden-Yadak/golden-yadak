# 🏎️ یدک‌آنلاین (Golden Yadak)

فروشگاه اینترنتی قطعات یدکی لوکس خودرو — رابط کاربری فارسی و راست‌چین (RTL).

## 🛠 پشته‌ی فناوری

- **React 19** + **Vite 8**
- **React Router DOM 7** (مسیریابی + تشخیص ساب‌دامین)
- **Tailwind CSS 4** (پلاگین رسمی `@tailwindcss/vite`)
- فونت **Vazirmatn** و آیکون‌های **Material Symbols**
- **Axios** (آماده برای اتصال به API)
- **ESLint**

## 📁 ساختار پروژه

```
.
├── index.html
├── public/              # فاوآیکون و آیکون‌ها
└── src/
    ├── main.jsx         # نقطه‌ی ورود
    ├── App.jsx          # مسیریابی + تشخیص ساب‌دامین (multi-tenant)
    ├── index.css        # استایل سراسری + متغیرهای رنگ طلایی
    ├── components/      # کامپوننت‌های مشترک (Header / Footer / ProductCard)
    ├── pages/           # صفحات (Homepage / Products / ProductDetail / Login / Verify / AdminDashboard)
    ├── data/            # داده‌ی نمونه (mock) — بعداً با API جایگزین می‌شه
    ├── lib/             # کانفیگ مرکزی (نام برند، اطلاعات تماس، تنظیمات محیط)
    └── hooks/           # هوک‌های سفارشی (آینده)
```

## 🚀 شروع به کار

```bash
npm install      # نصب وابستگی‌ها
npm run dev      # اجرای سرور توسعه (پیش‌نمایش زنده)
npm run build    # بیلد تولیدی
npm run preview  # پیش‌نمایش بیلد تولیدی
npm run lint     # بررسی کیفیت کد
```

## ⚙️ متغیرهای محیطی

یک فایل `.env` در ریشه بساز (الگوی `.env.example` موجود است):

```
VITE_BASE_DOMAIN=example.com   # دامنه‌ی اصلی برای تشخیص ساب‌دامین (multi-tenant)
```

## 🗺 وضعیت پروژه

پروژه در حال حاضر در **مرحله‌ی توسعه (development)** است:

- ✅ رابط کاربری کامل صفحات
- ✅ بازسازی ساختار و استخراج کامپوننت‌های مشترک
- ✅ جدا کردن داده‌های نمونه از UI
- 🔜 مدیریت state (سبد خرید، احراز هویت)
- 🔜 فرم‌های واقعی ورود / تأیید OTP
- 🔜 اتصال به API بک‌اند
- 🔜 آماده‌سازی برای پروداکشن

## 🎨 برند

نام برند، لوگو و اطلاعات تماس در `src/lib/config.js` به‌صورت متمرکز تعریف شده‌اند.
برای تغییر نام برند، فقط همین یک فایل را ویرایش کن.
